## photos.json (선택)

`photos.json`이 있으면 거기 적힌 이름만 불러옵니다 (없는 파일을 찾느라 생기는 404를 막기 위해 기본으로 빈 목록 `[]`을 둡니다).

- 사진을 넣었으면 이름을 추가: `["05-profile", "01-home-tonghakro"]`
- 귀찮으면 `photos.json`을 **지우세요** — 그러면 22자리를 자동으로 찾아봅니다 (콘솔에 404가 뜨지만 화면엔 문제 없음).
